# 機能仕様書 (Functional Specification)

## 1. 機能詳細
### 1.1 オーディオ出力制御機能
*   **デバイス列挙**:
    *   `navigator.mediaDevices.enumerateDevices()` を使用して、利用可能な音声出力デバイスのリストを取得する。
    *   デバイス名（ラベル）の取得には権限が必要なため、未取得時は「権限リクエスト」ボタンを表示する。
*   **出力先変更**:
    *   ユーザーがデバイスを選択すると、そのタブの音声をキャプチャし、指定されたデバイスへルーティングする。
    *   Webページ内の特定の `<audio>` タグではなく、**タブ全体の音声** が対象となる。

### 1.2 音量制御機能
*   **音量調整**:
    *   Popup のスライダーで 0% 〜 500% の調整が可能（デフォルトは 100%）。
    *   100% 超はブースト領域として扱い、パーセント表示を琥珀色にし、スライダー上の 100% 位置に区切り線を表示する。
    *   Web Audio API の `GainNode` を使用して制御するため、ページの元の音量設定とは独立して動作する（ページが100%でも、拡張機能で50%にすれば半減する。200% なら約2倍）。
    *   ブースト時のピーク歪みを緩和するため、`GainNode` の後段に `DynamicsCompressorNode`（リミッター設定）を接続する。
*   **ミュート切り替え**:
    *   ミュートボタンで瞬時に消音/解除が可能。
*   **100% リセット**:
    *   `100%` ボタンで音量をデフォルト（100%）に戻し、ミュート中なら解除する。
    *   すでに 100% かつ非ミュートのときはボタンを無効化する。

### 1.3 設定の保存と復元
*   **保存**: キャプチャ開始と `SET_DEVICE` / `SET_VOLUME` の適用が成功したときだけ、オリジンごとにデバイスと音量設定を保存する。失敗時は storage を更新しない。
*   **Popup 復元**: 次回同じサイトを開き Popup を開いた際、非デフォルト設定（デフォルト以外のデバイス / 音量 ≠ 100% / ミュート）があれば自動でキャプチャを開始し、設定を適用する。
*   **ブラウザ再起動後**:
    *   Chrome の制約上、再起動直後に自動キャプチャは行わない。
    *   代わりに、復元が必要なタブの拡張機能アイコンに `!` バッジを表示する。
    *   ユーザーがアイコンをクリックして Popup を開くと、保存済み設定の復元を試みる。
*   **キャプチャ再構築時の保持**: ストリーム再取得などでキャプチャが作り直されても、デバイス / 音量設定を維持する。
*   **stale pending の回避**: Chrome 側キャプチャが `pending` のまま固着した場合は、短時間の待機後に要操作（NeedsAction）へ遷移し、「復元中」のまま固まらないようにする。

### 1.4 多言語対応機能
*   **言語サポート**:
    *   **日本語 (ja)**: デフォルト言語。
    *   **英語 (en)**: ブラウザの言語設定が英語の場合に自動的に適用される。
*   **対応範囲**:
    *   Popup UI（タイトル、ラベル、ボタン、ステータス）
    *   権限リクエストページ
    *   拡張機能のメタデータ（名前、説明文）
    *   要操作バッジのツールチップ

## 2. 権限管理フロー
### 2.1 デバイス名取得権限
1.  **未許可状態**: Popup に「Permission needed」という警告と「Grant Permission」ボタンを表示。
2.  **リクエスト**: ボタンを押すと、新しいタブで `permissions.html` が開く。
3.  **許可**: ユーザーがブラウザのダイアログで「許可」を選択すると、成功メッセージが表示され、タブが自動的に閉じる。
4.  **反映**: Popup を再度開くと、デバイス名（例: "Headphones (WH-1000XM4)"）が正しく表示される。

## 3. UI状態定義
*   **初期状態**: Loading スピナーを表示。
*   **権限未取得**: デバイス選択肢が隠され、権限リクエストボタンが表示される。
*   **通常状態 (Ready)**: デバイス選択プルダウンと音量スライダーが操作可能。
*   **復元中 (Restoring)**: 保存設定の適用 / キャプチャ開始中。
*   **キャプチャ中 (Capturing)**: 音声ルーティングが有効。タブ上部に「このタブを共有しています」というChrome標準のインジケータも表示される。
*   **要操作 (NeedsAction)**: キャプチャが停止しており、ユーザー操作による復元が必要な状態。ツールバーバッジ `!` と連動する。
*   **エラー (Error)**: キャプチャやデバイス適用に失敗した状態。

## 4. エラーハンドリング
*   **接続エラー**: Offscreen Document との通信に失敗した場合、コンソールにエラーを出力し、UI を Error / NeedsAction に更新する。
*   **Offscreen 消失**: `Receiving end does not exist` の場合、Background が Offscreen を再作成して開始メッセージを 1 回再送する。再送も失敗したら Error / NeedsAction とする。
*   **キャプチャ終了**: ストリーム終了や `tabCapture` 停止時は `needs_action` とし、バッジ再表示で再操作を促す。
*   **stale pending**: `tabCapture` が `pending` のまま遷移しない場合は `needs_action` とし、ユーザー再操作を促す。
*   **非対応環境**: `setSinkId` がサポートされていないブラウザ（Chrome以外など）では、エラー状態を返しコンソールに警告を出す。
