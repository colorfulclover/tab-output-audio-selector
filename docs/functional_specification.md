# 機能仕様書 (Functional Specification)

## 1. 機能詳細
### 1.1 オーディオ出力制御機能
*   **デバイス列挙**:
    *   `navigator.mediaDevices.enumerateDevices()` を使用して、利用可能な音声出力デバイスのリストを取得する。
    *   デバイス名（ラベル）の取得には権限が必要なため、未取得時は「権限リクエスト」ボタンを表示する。
*   **出力先変更**:
    *   ユーザーがデバイスを選択すると、そのタブの音声をキャプチャし、指定されたデバイスへルーティングする。
    *   Webページ内の特定の `<audio>` タグではなく、**タブ全体の音声** が対象となる。

### 1.2 音量制御機能
*   **音量調整**:
    *   Popup のスライダーで 0% 〜 100% の調整が可能。
    *   Web Audio API の `GainNode` を使用して制御するため、ページの元の音量設定とは独立して動作する（ページが100%でも、拡張機能で50%にすれば半減する）。
*   **ミュート切り替え**:
    *   ミュートボタンで瞬時に消音/解除が可能。

### 1.3 設定の保存と復元
*   **保存**: URLごとにデバイスと音量設定を保存する。
*   **復元**: 次回同じサイトを開き、Popup を操作（または自動復元ロジックが発動）した際に、以前の設定を適用する。

## 2. 権限管理フロー
### 2.1 デバイス名取得権限
1.  **未許可状態**: Popup に「Permission needed」という警告と「Grant Permission」ボタンを表示。
2.  **リクエスト**: ボタンを押すと、新しいタブで `permissions.html` が開く。
3.  **許可**: ユーザーがブラウザのダイアログで「許可」を選択すると、成功メッセージが表示され、タブが自動的に閉じる。
4.  **反映**: Popup を再度開くと、デバイス名（例: "Headphones (WH-1000XM4)"）が正しく表示される。

## 3. UI状態定義
*   **初期状態**: Loading スピナーを表示。
*   **権限未取得**: デバイス選択肢が隠され、権限リクエストボタンが表示される。
*   **通常状態**: デバイス選択プルダウンと音量スライダーが操作可能。
*   **キャプチャ中**: タブ上部に「このタブを共有しています」というChrome標準のインジケータが表示される。

## 4. エラーハンドリング
*   **接続エラー**: Offscreen Document との通信に失敗した場合、コンソールにエラーを出力し、再接続を試みる。
*   **非対応環境**: `setSinkId` がサポートされていないブラウザ（Chrome以外など）では、コンソールに警告を出す。

### 1.4 多言語対応機能
*   **言語サポート**:
    *   **日本語 (ja)**: デフォルト言語。
    *   **英語 (en)**: ブラウザの言語設定が英語の場合に自動的に適用される。
*   **対応範囲**:
    *   Popup UI（タイトル、ラベル、ボタン、ステータス）
    *   権限リクエストページ
    *   拡張機能のメタデータ（名前、説明文）
