# 機能仕様書 (Functional Specification)

## 1. 機能詳細
### 1.1 オーディオ出力制御機能
*   **デバイス列挙**:
    *   `navigator.mediaDevices.enumerateDevices()` を使用して、利用可能な音声出力デバイス（`kind === 'audiooutput'`）のリストを取得する。
    *   **仕様**:
        *   Chrome拡張機能の仕様上、デバイスラベルの取得にはマイク権限などの許可が必要な場合がある。
        *   ユーザーが権限を許可していない場合、デバイスIDのみでラベルが空文字になるケースをハンドリングする（「Unknown Device 1」等と表示するか、権限リクエストUIを出す）。
        *   取得したリストの先頭には常に「既定のデバイス (Default)」を含める。
*   **出力先変更**:
    *   Popupで選択されたデバイスIDを、対象タブのDOM内にある全ての `<audio>` および `<video>` 要素に対して `setSinkId(deviceId)` を呼び出して適用する。
    *   **動的要素の検知**: `MutationObserver` を常時稼働させ、YouTubeの「次へ」遷移やSPA遷移で新たに生成されたメディア要素に対しても、即座に同じ設定を適用する。

### 1.2 音量制御機能
*   **音量調整**:
    *   **基本実装**: `HTMLMediaElement.volume` プロパティ（0.0〜1.0）を操作する。
    *   **拡張実装（Future）**: 100%を超える増幅が必要な場合は Web Audio API の `GainNode` を使用するが、CORSエラーのリスクがあるため、v1.0では基本実装を優先する。
*   **ミュート切り替え**:
    *   `HTMLMediaElement.muted` プロパティをトグルする。
    *   ミュート中はスライダーを無効化（グレーアウト）するなどのUIフィードバックを行う。

### 1.3 設定の保存と復元
*   **保存タイミング**:
    *   ユーザーがデバイス選択または音量スライダーを操作してから **500ms後** (Debounce) に `chrome.storage.local` へ書き込む。頻繁な書き込みによるパフォーマンス低下を防ぐ。
*   **復元ルール**:
    *   Content Scriptの初期化時（`window.onload` または `document_start`）、`location.origin` (ドメイン) をキーにストレージを検索する。
    *   保存された設定が見つかった場合、DOM内のメディア要素検知を待ち受け、検知次第 `setSinkId` と `volume` を適用する。

## 2. エラーハンドリング
| エラーケース | 検知方法 | 挙動・ユーザーへのフィードバック |
| :--- | :--- | :--- |
| デバイス使用権限なし | `enumerateDevices` で取得したデバイスの `label` が空文字 | Popup上部に警告バーを表示し、「権限を許可」ボタンを表示。クリックで権限リクエスト（`getUserMedia`）を実行。 |
| 指定デバイス未検出 | `setSinkId` が `NotFoundError` をスロー | 保存された設定を破棄し、「既定のデバイス」にフォールバックする。ユーザーにはToast通知で「デバイスが見つかりません」と伝える。 |
| 非対応ページ | メディア要素が1つも検出されない | Popupのコントロールを無効化（Disabled）し、「このページには音声がありません」と表示する。 |
| CORSエラー | Web Audio API 接続時の `SecurityError` | コンソールに警告を出力し、標準API（`.volume`）へのフォールバックを試みる。 |

## 3. UI状態定義
*   **初期状態 (Loading)**:
    *   Popupを開いた直後。Backgroundからのタブ情報取得と、デバイス一覧取得が完了するまでスケルトンローダーを表示する。
*   **通常状態 (Active)**:
    *   タブ情報、デバイス一覧、現在の設定値が揃った状態。
    *   現在再生中のメディアがある場合、波形アニメーション（またはインジケータ）を表示して視認性を高める。
*   **権限未取得状態 (Permission Required)**:
    *   デバイスリストのラベルが取得できない場合。
    *   デバイス選択プルダウンの代わりに「デバイス名の取得を許可する」ボタンを表示する。
