# テスト仕様書 (Test Specification)

## 1. テスト方針 (Test Strategy)
### 1.1 手動テスト (Manual Tests / E2E)
*   オーディオ出力の物理的な切り替え確認は、ハードウェア依存のため手動で行う。
*   テスト環境: Google Chrome (Latest Stable), 複数のオーディオデバイス（スピーカー、ヘッドフォン等）。

### 1.2 自動テスト (Unit Tests)
*   Vitest により、キャプチャ設定・ライフサイクル・Offscreen ハンドラのロジックを検証する。
*   実行コマンド: `pnpm test`

## 2. テストケース一覧
### 2.1 手動機能テスト (Manual Functional Tests)
| ID | カテゴリ | 手順 (Action) | 確認項目 (Check) |
| :--- | :--- | :--- | :--- |
| M-01 | 権限取得 | Popupの「Grant Permission」をクリック | 新規タブで `permissions.html` が開くこと |
| M-02 | 権限許可 | `permissions.html` で「許可」をクリック | ブラウザのマイク権限プロンプトが表示され、許可後に「Granted」と表示されタブが閉じること |
| M-03 | デバイス表示 | 権限取得後にPopupを開く | 「Default」以外の具体的なデバイス名（例: Speakers, Headphones）が表示されること |
| M-04 | キャプチャ開始 | デバイスまたは音量を変更 | タブ上部に「このタブを共有しています」という青いバー（またはアイコン）が表示されること |
| M-05 | デバイス変更 | YouTube再生中にPopupで出力先を変更 | 音声が指定したデバイスから出力され、元のデバイスからは消えること |
| M-06 | 音量変更 | Popupのスライダーを操作 | 0%〜500% の範囲で音量が変化すること（デフォルトは 100%） |
| M-06a | 音量ブースト UI | スライダーを 100% 超へ操作 | パーセント表示が琥珀色になり、100% 位置の区切り線が見えること |
| M-06b | 高ブースト | スライダーを 500% 付近へ操作 | 音量が増大し、極端なピークでも破綻が緩和されていること（体感） |
| M-06c | 100% リセット | ブーストまたはミュート後に `100%` ボタンを押す | 音量が 100% になりミュートが解除されること。既に 100%・非ミュートならボタン無効 |
| M-07 | 設定保存 | 設定変更後にタブをリロード | リロード後、Popupを開くと以前の設定値（音量・デバイス）が復元されていること |
| M-07a | ブースト保存復元 | 音量を 250% など 100% 超で保存し Popup を再オープン | 250% が復元され、ブースト表示が維持されること |
| M-08 | 再起動後バッジ | 非デフォルト設定を保存した状態で Chrome を再起動 | 該当タブの拡張機能アイコンに `!` バッジが表示されること |
| M-09 | 再起動後復元 | M-08 の状態でアイコンをクリック | Popup が自動でキャプチャを開始し、保存済みのデバイス / 音量が再適用されること |
| M-10 | キャプチャ再構築 | キャプチャ中に再開始が必要な操作を行う | デバイス / 音量設定が維持されること |
| M-11 | 失敗時非保存 | キャプチャ失敗状態でスライダー等を操作 | Footer が NeedsAction / Error になり、storage の値が変わらないこと |
| M-12 | Offscreen 再読込後 | 拡張機能を再読み込みしたあと Popup で設定操作 | リトライで復旧するか、NeedsAction になり Restoring のまま固まらないこと |

### 2.2 UI/UXテスト
| ID | 画面 | 手順 | 確認項目 |
| :--- | :--- | :--- | :--- |
| UI-01 | Popup | アイコンクリック | 即座に表示され、エラーなくロードされること |
| UI-02 | Popup | ダークモード | システム設定に合わせて配色が切り替わること |
| UI-03 | Footer | キャプチャ状態の変化 | Ready / Restoring / Capturing / NeedsAction / Error が正しく表示されること |
| UI-04 | Toolbar | NeedsAction | バッジ `!` とツールチップ文言が表示されること |
| UI-05 | Volume | 100% 以下 / 超 | 100% 以下は通常色、超えると琥珀色＋100% マーカーが表示されること |

### 2.3 自動テスト (Unit)
| ID | 対象 | 確認項目 |
| :--- | :--- | :--- |
| U-01 | `capture-settings` | URL に紐づく保存設定の読み込みと、URL 不在時の undefined 返却 |
| U-02 | `capture-lifecycle` | コールドスタート時のバッジ付与、アクティブキャプチャの除外、同時リクエストの合流 |
| U-03 | `offscreen-handler` | 復元設定の適用、キャプチャ再構築時の設定保持、応答ステータスの返却 |
| U-04 | `capture-lifecycle` | stale `pending` → `needs_action`、`pending`→`active` 再利用、`pending` 消失後の再開始 |
| U-05 | `offscreen-messaging` | `Receiving end does not exist` 時の 1 回リトライ、無関係エラーでは再作成しないこと |
| U-06 | `volume` / `capture-settings` | `clampVolume` が 0〜5 に正規化すること、ブースト音量が非デフォルト判定されること |
