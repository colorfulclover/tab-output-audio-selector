# テスト仕様書 (Test Specification)

## 1. テスト方針 (Test Strategy)
### 1.1 手動テスト (Manual Tests / E2E)
*   オーディオ出力の物理的な切り替え確認は、ハードウェア依存のため手動で行う。
*   テスト環境: Google Chrome (Latest Stable), 複数のオーディオデバイス（スピーカー、ヘッドフォン等）。

## 2. テストケース一覧
### 2.1 手動機能テスト (Manual Functional Tests)
| ID | カテゴリ | 手順 (Action) | 確認項目 (Check) |
| :--- | :--- | :--- | :--- |
| M-01 | 権限取得 | Popupの「Grant Permission」をクリック | 新規タブで `permissions.html` が開くこと |
| M-02 | 権限許可 | `permissions.html` で「許可」をクリック | ブラウザのマイク権限プロンプトが表示され、許可後に「Granted」と表示されタブが閉じること |
| M-03 | デバイス表示 | 権限取得後にPopupを開く | 「Default」以外の具体的なデバイス名（例: Speakers, Headphones）が表示されること |
| M-04 | キャプチャ開始 | デバイスまたは音量を変更 | タブ上部に「このタブを共有しています」という青いバー（またはアイコン）が表示されること |
| M-05 | デバイス変更 | YouTube再生中にPopupで出力先を変更 | 音声が指定したデバイスから出力され、元のデバイスからは消えること |
| M-06 | 音量変更 | Popupのスライダーを操作 | 音量が変化すること |
| M-07 | 設定保存 | 設定変更後にタブをリロード | リロード後、Popupを開くと以前の設定値（音量・デバイス）が復元されていること |

### 2.2 UI/UXテスト
| ID | 画面 | 手順 | 確認項目 |
| :--- | :--- | :--- | :--- |
| UI-01 | Popup | アイコンクリック | 即座に表示され、エラーなくロードされること |
