# 要件定義書 (Requirement Definition)

## 1. プロジェクト概要
### 1.1 背景と目的
現代のブラウザ利用においては、オンライン会議（Google Meet, Zoom等）と動画視聴（YouTube等）や音楽再生を同時に行うシチュエーションが増加している。
しかし、Chrome標準の機能では「タブごと」にオーディオ出力デバイスを振り分けることができない。
本プロジェクトは、Chrome拡張機能を用いることで、タブごとに「出力先デバイス」と「音量」を個別に制御可能にし、会議とBGMの共存など、快適なマルチタスク環境を提供することを目的とする。

### 1.2 ターゲットユーザー
*   **メインユーザー**: 日常的にGoogle Chromeを利用し、複数のタブで同時に音声メディアを再生するユーザー。
*   **利用シーン例**:
    *   オンライン会議の音声は「スピーカー」から出力し、裏で流しているBGM（音楽）は「ヘッドフォン」から流す。
    *   会議中にBGMの音量だけを絞る。

## 2. 機能要件 (Functional Requirements)
### 2.1 ユーザーストーリー
| ID | ユーザー | 実行したいこと (Action) | 期待する結果 (Outcome) | 優先度 |
| :--- | :--- | :--- | :--- | :--- |
| F-01 | ユーザー | 特定のタブのオーディオ出力先を変更する | そのタブの音声だけ指定したデバイス（ヘッドフォン/スピーカー等）から再生される | **Must (高)** |
| F-02 | ユーザー | 特定のタブの音量を変更する | そのタブの音声だけ音量が変わる（会議音声はそのまま、音楽だけ下げる等） | **Must (高)** |
| F-03 | ユーザー | ポップアップから現在の設定を確認する | どのタブがどのデバイスに出力されているか一覧・確認できる | Must (高) |
| F-04 | ユーザー | 設定を保存する | ブラウザやタブを閉じても、次回開いた際に前回の出力先・音量設定が維持される | Nice (中) |

### 2.2 機能一覧
*   **オーディオ制御機能**:
    *   出力デバイスの列挙（`navigator.mediaDevices.enumerateDevices`）
    *   出力デバイスの選択・変更（`setSinkId`）
    *   音量（ゲイン）の個別調整（Web Audio API）
*   **UI機能**:
    *   拡張機能ポップアップ（Browser Action）
    *   デバイス選択ドロップダウン
    *   音量スライダー
*   **設定管理**:
    *   設定の永続化（`chrome.storage`） ※Nice-to-haveだが、ユーザビリティ向上のため初期実装を目指す

## 3. 非機能要件 (Non-Functional Requirements)
### 3.1 性能・パフォーマンス
*   オーディオ処理（AudioContext）による遅延が、動画のリップシンク（口の動きとの同期）を著しく損なわないこと。
*   不要なタブでのメモリ消費を抑える（使用していないAudioContextはサスペンドまたはクローズする）。

### 3.2 セキュリティ・権限
*   **Manifest V3準拠**: リモートコード実行を行わず、セキュアな実装とする。
*   **権限 (Permissions)**:
    *   `tabCapture` (または `activeTab` + `scripting`): 音声ストリームのキャプチャおよび制御用。
    *   `storage`: 設定保存用。

### 3.3 ユーザビリティ
*   2クリック以内で出力先変更が完了するシンプルなUI。
*   Svelte + WXT によるモダンでレスポンシブな操作感。

## 4. 制約条件 (Constraints)
*   **プラットフォーム**: Google Chrome (最新版)
*   **技術スタック**:
    *   Framework: **WXT**
    *   UI Library: **Svelte**
    *   Language: **TypeScript**
*   **配布形態**: Chrome Web Store (審査基準への適合)

## 5. 将来の拡張性 (Future Scope)
*   サイトごとのデフォルト設定（ドメイン単位での設定保存）
*   イコライザー機能
*   ショートカットキーによるミュート切り替え
